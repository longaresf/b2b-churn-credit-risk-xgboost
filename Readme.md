# Clasificación utilizando XGBoost

## Descripción
Este proyecto tiene como objetivo analizar datos de predicción de enfermedades del corazón de la UCI con información sobre varios factores de riesgo asociados con enfermedades cardíacas. La importancia de este análisis radica en optimizar el modelo XGBoost para mejorar la toma de decisiones en relación a los clientes.

## Estructura del Repositorio
- **dataset/**: Contiene dataset utilizado para el análisis y modelado.
- **notebook/**: Jupyter Notebook con el desarrollo de todo el proceso de análisis exploratorio, preprocesamiento y modelado.
- **README.md**: Documento de presentación y guía del proyecto.

## Instrucciones para Ejecutar
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/longaresf/Analisis_de_Datos_Clasificacion_XGBoost.git
   ```
2. Ejecutar el notebook: Francisco_Longares_Clasificacion_XGBoost.ipynb, siguiendo el orden sugerido en los títulos.
3. El dataframe se encuentra en la carpeta dataset/.
